# Machine-Learning-Project-

Title : A manufacturing quality prediction system

Project Description:

The Manufacturing Quality Prediction System is a machine learning and computer vision-based application designed to automatically detect defects in manufactured products. We will use the MVTec AD Bottle dataset, which contains defect-free and defective bottle images along with ground-truth defect masks.

The system will analyze uploaded bottle images, identify potential defects, highlight suspicious regions, and classify products as normal or potentially defective. A web-based dashboard will display inspection results, anomaly scores, and inspection statistics.

Technologies: Python, PyTorch, OpenCV, Pandas, NumPy, Scikit-learn, and Streamlit.
